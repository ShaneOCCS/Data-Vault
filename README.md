# StudentAuth Portal - Local Setup Guide

This is a Next.js project built with React, Tailwind CSS, and ShadCN UI. Follow these steps to run the project on your local machine.

## Prerequisites

Ensure you have **Node.js** (v18 or later) installed on your system.

## Getting Started

1. **Extract the ZIP**: Unzip the downloaded folder to a location on your computer.
2. **Open Terminal**: Open your terminal (Command Prompt, PowerShell, or Terminal) and navigate to the project directory:
   ```bash
   cd path/to/your/extracted-folder
   ```
3. **Install Dependencies**: Run the following command to install the required packages:
   ```bash
   npm install
   ```
4. **Run Development Server**: Start the local development server:
   ```bash
   npm run dev
   ```
5. **Access the App**: Open your browser and navigate to:
   [http://localhost:9002](http://localhost:9002)

## Project Scripts

- `npm run dev`: Starts the development server on port 9002.
- `npm run build`: Creates an optimized production build.
- `npm run start`: Starts the production server.
- `npm run lint`: Runs ESLint to check for code quality issues.

## Demo Credentials

You can find a list of demo Student IDs and Registration Codes by clicking the **"Demo Credentials"** button on the Login page within the app.
